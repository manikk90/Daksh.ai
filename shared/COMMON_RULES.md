# Shared Agent Operating Contract

Version: 2026-11-01 | Owner: Manik | Language: Hinglish for collaboration; preserve requested artifact language.

## Priority of truth
1. Current direct user request and explicit corrections.
2. Current approved project-specific frame, source and character locks.
3. Verified current source or accessible file revision.
4. Saved agent rules and project memory.
5. Research-backed suggestions, explicitly marked as proposals.

Never turn a local shot instruction into a universal rule. Never substitute generated illustrations for the actual requested source asset or claim a prompt is a rendered result.

## Universal execution loop
Intake -> exact output contract -> retrieve only relevant context -> execute -> check -> independent review if substantial -> deliver -> persist scoped verified lessons when available. Each run records objective, project, inputs/source revisions, exact locks, outputs, QC, unresolved items and next owner. Don't silently publish, send, spend, train models or create automations.

## Daily/weekly learning
Requested baseline: accessible chat/correction learning at 23:00 Asia/Kolkata; relevant official research on Sunday nights at 23:00. Actual per-agent scheduler ownership and active state must be confirmed rather than inferred. Writer and Location have had separate ownership/exceptions and must not be duplicated or automatically resumed. Scheduled coverage is not proof of full conversation or device access. Learning changes only scoped instructions and tested records, not protected production canon.

## Cross-agent handoff schema
```
project; episode; scene; shot_id; request; source_assets; source_revision; approved_locks; visible_characters; visible_props; location_tags; offscreen_audio; target_language; output_format; duration; owner; acceptance_checks; unresolved_dependencies; artifact_paths; qc_result
```

Keep visible entities local to the shot. Label offscreen speakers separately. A handoff is not proof that another worker actually ran.

## QC stop conditions
Stop or mark pending on unavailable media, unverified character/face identity, wrong physical geography, invented location suffixes, omitted shot ID, nonmatching spoken words, failed user approval gate, broken links, stale versions, unverified sources or missing authorization. When possible, deliver a partial verifiable result and name the blocker.
