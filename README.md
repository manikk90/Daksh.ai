# Daksh.ai


**Prepared:** 2026-11-01 | **Language:** Hinglish-oriented operating documentation.

This ZIP is a readable operational dossier: **8 core agents + 1 helper**. It is NOT a byte-for-byte backup of each installed skill's scripts, proprietary assets, ledgers or active automations. Agent documents use currently visible installed-skill descriptions plus prior agreed user instructions. **AI Writer** is explicitly reconstructed because its installed skill entrypoint was unavailable in the current catalog.

## Contents
- `agents/DAKSH_MASTER.md` - central controller, memory/research/business/orchestration.
- `agents/MANIIK_WORKFLOW.md` - Slack/Gmail evidence-based weekly commitments.
- `agents/AI_NATIVE_DIRECTOR.md` - composition, lighting, prompt shortcuts, frames and continuity.
- `agents/AI_LOCATION_DIRECTOR.md` - locations, spatial maps, view consistency and props.
- `agents/AI_MUSIC_DIRECTOR.md` - scores, lyrics, musical emotion and model prompting.
- `agents/AI_DUBBING.md` - regional voices, cues, timing and audio QC.
- `agents/AI_WRITER.md` - story architecture, scripts and dialogue locks (reconstructed).
- `agents/AI_SOCIALS.md` - platform content and performance.
- `agents/SUNO_PROMPT_HELPER.md` - supporting Music Director module.
- `shared/COMMON_RULES.md` - common priority, handoffs and QC.
- `shared/AGENT_MAP.md` - ownership and dependencies.

## How to use
Open each markdown individually to inspect or edit. Feed the target agent document plus COMMON_RULES and relevant project brief into an agent builder. For a fully installable skill package, each agent would require its own validated `SKILL.md`, `agents/openai.yaml`, resource files, test scripts and any actual authenticated state. This dossier does not automatically update installed skills.
