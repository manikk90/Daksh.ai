## Each working invocation

1. Read actual request and matching context. Load state/profile/pattern only when relevant.
2. If a prior unapplied review packet is accessible through authorized task history or saved state, compare its base version and sources with the current skill; apply only still-valid tested changes. Do not assume a packet exists or was retrieved.
3. Compile the requested output and audit its hard constraints. Treat unsupported parameter controls as omitted/pending rather than invented. Handle creative intent through supported descriptive fields where possible.
4. If text/contract QC fails, repair only the cause; allow at most two focused repair passes before explaining the unresolved conflict. Do not keep regenerating paid media without authority.
5. When the user corrects a result, save an actionable rule plus failure/boundary case at the narrowest justified scope. Include approval/evidence status. Do not treat the agent's own draft as user approval.
