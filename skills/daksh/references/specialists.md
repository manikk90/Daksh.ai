# Specialist routing

Resolve/read the current relevant skill branch using `assets/agent-registry.json`; names below do not prove a worker ran or all recent changes saved. Use [master-orchestration.md](master-orchestration.md) for actual dispatch/state/review. Keep one owner for canonical writes and pass source/version/locks. A micro-edit needs the relevant procedure, not a whole team.

| Work | Target | Handoff |
|---|---|---|
| Story, synopsis, screenplay, rewriting, breakdown | AI Writer / ai-writer | Format/genre/runtime, actual source revision, exact lines and requested scope. |
| Camera, performance, boards, cast/costume | AI Native Director | Scene/shot/version, profiles, exact references/tags, contact/perception/grade locks. |
| Connected locations, 360, props | AI Location Director | Approved master, geography, routes/shared boundaries, exact requested views. |
| Music, songs, lyrics, score | AI Music Director | Emotional arc, vocal/instrumental status, instruments/lyrics locks, actual platform. |
| Voice, tone, regional dubbing, sync | Ai Dubbing | Speaker, exact line, variety, voice/picture/source version and timing. |
| Simple instrumental Suno prompt | Suno Instrumental Prompts | Cue and normally 800 characters including instrumental exclusions. |
| Social research, content plans and platform drafts | AI Socials, when currently available | Platform/purpose, source claims, actual writing samples, approved image/text locks; drafts without publishing authority. |
| AI research synthesis, business hypotheses, action learning | Daksh internal focused roles | Relevant source evidence and dates, actual user choices, uncertainty, falsifiable next step. Spawn only if separable work merits it. |
| Consultancy offers, portfolio, pilot sales preparation and secure delivery | AI Consultant | Use [the shared workflow](opportunity-sync.md); reuse verified 02:00 IST opportunity leads, add source, buyer, offer and one low-cost test. Sending or sharing needs applicable authorization. |
| Independent final review | Fresh scoped QC worker | Raw sources, current locks and candidate artifacts; no expected verdict or shared producer reasoning. |
| Metrics, KPIs, sizing, data-backed decisions | Data index/focused workflow | Source data, grain/definitions, question and uncertainty. |
| Writing in Manik's voice | Write Like Me plus artifact/writing workflow | Real relevant user samples, purpose, audience and scope; no sending by default. |
| Weekly commitments, Slack/mail priorities and morning work briefing | maniik | Resolve current skill/task; actual assignment/owner/deadline, concise final update. Calendar task/reminder is distinct from a meeting. |
| Files/sites/calendar/communications | Purpose-built skill/connector | Exact action/artifact and verified recipients where applicable. |

Resolve every installed name at run time, including skills added after this registry was written. A local AI Socials directory does not by itself establish saved installation. For substantial handoffs distinguish self-review from independent QC. Do not automatically edit other specialists during Daksh maintenance. Keep existing Director/Location/audio/briefing schedules separate and avoid duplicate tasks. Queue cross-skill proposals unless that scope is independently authorized.
