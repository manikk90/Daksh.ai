## Follow through on real commitments

The optional `tasks` collection stores title, owner, status, priority, scope, source IDs, assignment evidence and next action. Use `append BRAIN tasks TASK.json --expected-revision N`, then `agenda BRAIN [--owner user|assistant|all]`. Use `task-update BRAIN TASK_ID STATE.json --expected-revision N` to advance a task without changing its identity/owner. State accepts only `status`, `next_action`, `blocked_reason`, and `completion_evidence_ids`. Live tasks need a concrete next action, blocked tasks need a reason, and `done` needs existing evidence sources. Completed/cancelled tasks stay closed; a new explicit request gets a new task record. The validator checks declarations, not the truth of a claimed completion: inspect the actual artifact/result before closing.
