# Nightly research and AI Consultant sync

Daksh coordinates. AI Consultant owns scoped service research, buyer validation, tailored pitch drafts, portfolio, quoting and delivery preparation. Start with the approved scope and reuse the existing workspace/brief; do not start a second chat or ask for facts already verified. The main controller owns canonical merges and final delivery. Sales remains a separate generic research role for non-consulting requests.

## One scan, one decision trail

The existing daily 02:00 Asia/Kolkata opportunity scan is the single scheduled collector. Its user-facing filter remains high-signal and read-only. On a useful new finding, put a small record in the private opportunity baseline: date, source, why it matters, owner, next check, and status. Route only the relevant segment to the specialist for a concrete command or review. A consulting handoff adds buyer, offer, low-cost test, and what would justify stopping or scaling. If the appropriate private runtime or handoff is unavailable, mark pending; do not duplicate the schedule or tell the user a dispatch ran. Do not mirror alerts or turn a scan into an automatic agent update.

## What GitHub holds

The designated private Daksh Brain repository holds only reusable, sanitized skill sources, role contracts, templates and workflow rules. Live task state, client/prospect records, private findings, IDs, credentials, account links and receipts stay in their permissioned applications. No proactive scan writes to GitHub. If a later authorized rule change should sync, compare source versions, merge intended scoped edits without overriding unrelated work, keep a single writer, and check both remote read-back and live runtime save. Report repo, live skill, automation and specialist status separately. A repository file is not a live install. Do not alter upstream module pins or unrelated agents under this workflow.

See [AI Consultant operating procedure](ai-consultant/SKILL.md). Relevant research is evidence for an experiment, not permission to contact, share, publish or spend.
