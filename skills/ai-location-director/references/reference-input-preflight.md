# Reference input preflight

Before passing an approved location/prop reference into generation, record its actual dimensions, intended aspect ratio, selected interface and reference role. Keep a user-locked full view, four-view prop contract and camera orientation intact.

Runway's input documentation warns that ratio mismatches can crop inputs and that third-party routes may behave differently. Check frame-edge architecture, entrances, steps and props against the selected route. Do not automatically crop or expand an approved image, invent missing geometry or alter tag bindings to accommodate the interface. A crop overlay is diagnostic only; it is not an accepted replacement master.

Record unresolved preparation as pending and hand the approved reference role and dimensions to AI Native Director. Inspect actual outputs separately; this check cannot verify cross-view geometry or image fidelity.
