# God Mode reports

Every `gm` run saves its blueprint here, so that research compounds instead of repeating.

- File name: `YYYY-MM-DD-<short-slug>.md`, for example `2026-11-02-devotional-song-pipeline.md`.
- Format: [blueprint template](../../skills/god-mode/references/blueprint-template.md).
- Before a new run, check this folder for a related report. Reuse its findings and refresh only the claims that change fast (tools, models, prices).
- Keep the status honest: `proposal` (researched), `built` (files added to the repo) or `tested` (an experiment was actually run, with results).
